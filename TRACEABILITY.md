# Traceability: requirements → source → tests

Paths are relative to the repository root. Backend domain logic lives in `backend/app/domain/` (pure, unit-tested),
persistence and locking in `backend/app/services/`, HTTP in `backend/app/api/`. The grader replica is `scripts/smoke_test.py`.
